# Render deploy (paid — optional)

> **Render requires a paid plan** for this app (Docker web service + persistent disk for report images).  
> If you cannot use paid hosting, use **[HOSTING.md](./HOSTING.md)** — local Docker is free.

If your org has a Render budget:

1. [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint**
2. Select `nawaz-md-trmb/design-lens`
3. Apply `render.yaml` (Starter + 5GB disk)

See Render pricing before proceeding.
